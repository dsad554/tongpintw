# 同频提问局

围绕共同问题完成一次知识交换，留下两个人的新理解。此目录包含本地 HTML 项目和独立产品说明计划书。

当前阶段：内容精简与本地试用，暂不进行公网发布。本地预览已包含同源房间 API，可在两个网页标签页间共享问题、匹配和消息；仍不是跨设备云服务。题目、人物与完整案例均为自创示例；尚未接入真实知乎检索、实时 AI 或账号登录。

## 打开项目

双击 `打开项目.html`，也可直接打开 `dist/index.html`。推荐双击 `启动本地预览.cmd`，在浏览器打开终端给出的 Local 地址；终端保持运行，按 Ctrl+C 停止。本地服务仅监听 `127.0.0.1`，只提供 `dist/` 静态文件。

发布问题后可直接进入匹配；回应者需填写昵称和想解决的问题后加入。两个同源页面通过本地预览 API 共享问题和消息。关闭页面后，本地浏览器数据仍可恢复；跨设备使用需要部署后端。

好友已作为顶部独立页面：在交流房间点击“添加好友”，对方在“好友”页通过后，双方会按这次问题中的提问者、解决者或社群好友自动归类。三组列表可折叠；成为好友后可在自己的页面改为自定义分区。好友关系保存在网页目录外的 `数据/本地状态.json`，不写入公开 `dist/`。

登录说明：邮箱登录需要用户表、验证码/邮件服务、会话管理与 HTTPS；知乎登录需要知乎 OAuth 应用、Client ID/Secret、回调地址和服务端会话。当前项目没有这些服务和配置，不会在静态网页中伪造登录成功。

## 验证与打包

需要已安装的 Node.js 22+、PowerShell 7.4+，无 npm 依赖。

```powershell
node 工具/验证卡片逻辑.cjs
pwsh -NoProfile -File 工具/打包项目.ps1 -Kind 完整
pwsh -NoProfile -File 工具/打包项目.ps1 -Kind 网页
pwsh -NoProfile -File 工具/打包项目.ps1 -Kind 计划书
```

网页包仅包含 `dist/`；完整包包含项目、说明与工具。测试结论以实际生成的验收记录为准。当前未部署、未提交参赛；本地使用确认通过后再准备公网版本。
