# 交流板块更新记录

本轮新增：

- 问题按板块发布；发布后留在板块列表，选择同一问题后进入匹配房间。
- A/B 角色分开记录消息；同源两个标签页通过 `storage` 与 `BroadcastChannel` 看到同一房间更新。
- 结束前可持续交流；结束后双方分别选择关键句、提交总结和分类；双方确认后才生成成果卡。
- 成果卡长期保存在书架，可分类筛选、复制或系统分享。
- AI 只通过服务端端点获取相近知乎公开回答；没有 `found:true` 和有效 `reply` 时不显示回复。

## 仍需后端的部分

跨设备实时互通不能由静态 HTML 保证。正式版本需要后端房间、WebSocket/SSE、身份或访客标识、消息持久化、断线重连、限流、举报/屏蔽和删除机制。知乎 Access Secret 与模型密钥都必须留在服务端或系统凭据库，不能写入前端。
